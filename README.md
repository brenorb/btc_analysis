# btc_analysis
Analysis and models for bitcoin using only its price data

**Installation**

1. Clone the repository and enter it: `git clone https://github.com/brenorb/btc_analysis.git && cd btc_analysis`
2. Install the required packages: `pip install -r requirements.txt`
3. Download the dataset [from Kaggle](https://www.kaggle.com/mczielinski/bitcoin-historical-data) and extract `btcusd_1-min_data.csv` into the repository root, next to the notebook.
4. Start Jupyter from the repository root: `jupyter notebook`

**Usage**

1. Open the [`BrenoBrito-Bipa.ipynb`](BrenoBrito-Bipa.ipynb) notebook in Jupyter.
2. Run each cell in sequence to execute the analysis and models.
3. Adjust parameters and inputs as needed for your specific analysis.
4. Explore the visualizations and insights generated by the notebook.

**Note**: Ensure you have Jupyter installed and running on your system. If not, install Jupyter using `pip install jupyter`.
